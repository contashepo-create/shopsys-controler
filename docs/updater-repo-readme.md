# مركز تحكم المطور — رف الإصدارات (التحديث التلقائي)

**هذا المستودع لا يحتوي أي كود إطلاقاً.** وظيفته الوحيدة: استضافة **إصدارات**
تطبيق «مركز تحكم المطور» وملفات التحديث التلقائي التي يقرأها التطبيق عند المالك.

## لماذا فصلناه؟

- كود اللوحة (المفاتيح، الربط، التوقيع، واجهة الإدارة) يبقى في **مستودع خاص** لا يراه أحد.
- التطبيق يحتاج قراءة **عامة** ليعرف أن هناك إصداراً جديداً **بلا توكن** — فلو كان
  المستودع الخاص هو نفسه مصدر التحديث لاحتاج التطبيق توكن مدفوناً داخله، وهذا ثغرة.
- هنا: إصدارات فقط. لا كود، ولا أسرار، ولا شيء قابل للاختراق أو التلاعب بالكود.

## الملفات في كل إصدار

| الملف | الدور |
|---|---|
| `shopsys-controler-setup-<الإصدار>.exe` | مثبّت NSIS — هو ما ينزّله التحديث التلقائي |
| `shopsys-controler-setup-<الإصدار>.exe.blockmap` | تنزيل تفاضلي (أجزاء المتغيّر فقط) |
| `shopsys-controler-portable-<الإصدار>.zip` | نسخة محمولة بلا تثبيت |
| `latest.yml` | فهرس الإصدار الذي يقرأه `electron-updater` داخل اللوحة |

## كيف تُنشأ الإصدارات؟

آلياً بالكامل: أي تحديث للكود في المستودع الخاص → سير `auto-release` يرفع رقم النسخة
ويوسمها → سير `release-windows` يفحص ويبني وينشر إلى هنا.

> ⚠️ لا تُرفع إصدارات يدوياً هنا، ولا يُضاف أي كود لهذا المستودع.

## النسخ والتحديث

من التطبيق المثبّت: يفحص الإصدارات تلقائياً بعد الإقلاع ثم كل 6 ساعات، ينزّل التحديث
في الخلفية، ويُثبّته عند إغلاق اللوحة. بيانات المالك (كلمة المرور، مفاتيح Cloudflare،
توكن البوت، مفتاح التوقيع) محفوظة على جهازه ولا تُمسّ عند التحديث.
