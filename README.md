# shopsys-controler

## «مركز تحكم المطور» — Shopsys Controler

لوحة تحكم احترافية **لسطح المكتب (ويندوز)** مخصصة للمطوّر، تُبنى هنا بشكل مستقل عن
التطبيق الأساسي [shopsys «تَحَكَّم»](https://github.com/contashepo-create/shopsys)،
وبنفس لغته (**TypeScript** + React + Electron) ومع **مثبّت NSIS**.

هي نسخة مكتبية احترافية من **بوت تليجرام المطور** (`tools/devbot` في ريبو shopsys)،
تعمل **بالتزامن** معه على نفس بيانات Cloudflare KV.

### ماذا تفعل؟
- 🔑 التحكم في تراخيص العملاء: إصدار / تجديد / حرق / بحث (Ed25519 — نفس تنسيق التطبيق)
- ✅ تنشيط وإلغاء تنشيط العملاء
- 🧩 تفعيل/إلغاء تفعيل قسم أو ميزة إضافية لكل عميل
- 👥 رصد جميع العملاء: حالة الاشتراك، تاريخ آخر ظهور، والتحكم بهم
- 🎧 قناة دعم بين المطور والعملاء (قراءة + رد)
- 🔔 إشعارات للعملاء: فردي / مجموعة / جميع العملاء / عملاء نشاط معين
- 📝 محتوى «حول» + Feature flags
- 🧾 سجل تدقيق محلي لكل عملية حساسة
- ⚙️ إعدادات: مفتاح Cloudflare (Account ID + API Token + Namespaces) + توكن البوت + تغيير كلمة المرور (OTP عبر البوت)

### ما لا تفعله (مستبعد صراحة)
- ❌ لا نسخ احتياطية لقواعد بيانات العملاء
- ❌ لا وصول لأي بيانات محاسبية/تجارية للعملاء

### الإصدار والتنزيل — مستودعان: كود خاص + رف إصدارات عام

| المستودع | الظهور | ماذا يحتوي |
|---|---|---|
| [`shopsys-controler`](https://github.com/contashepo-create/shopsys-controler) (هذا) | **خاص** | كل الكود — لا يراه أحد |
| [`shopsys-controler-updater`](https://github.com/contashepo-create/shopsys-controler-updater) | **عام** | الإصدارات وملفات التحديث فقط — **بلا أي كود** |

**التنزيل دائماً من رف الإصدارات العام:** `shopsys-controler-setup-<version>.exe`

| الملف | الحجم | الوصف |
|---|---|---|
| `shopsys-controler-setup-<الإصدار>.exe` | ~109 MB | المثبّت (NSIS) — اختصار «تحكم المطور» — وهو ما ينزّله التحديث |
| `shopsys-controler-portable-<الإصدار>.zip` | ~160 MB | نسخة محمولة بلا تثبيت |
| `latest.yml` + `.blockmap` | صغيرة | فهرس التحديث الذي يقرأه `electron-updater` داخل اللوحة |

#### كيف يتحدّث التطبيق؟
- **تلقائي بالكامل**: يفحص رف الإصدارات بعد الإقلاع بـ12 ثانية ثم كل 6 ساعات.
- **التنزيل في الخلفية** بلا إزعاج، و**التثبيت عند إغلاق اللوحة** (أو فوراً بزر «إعادة التشغيل والتثبيت الآن»).
- **بياناتك لا تُمسّ**: كلمة المرور ومفاتيح Cloudflare والبوت ومفتاح التوقيع محفوظة في مجلد
  بياناتك على جهازك، والتحديث يثبّت فوق القديم فلا تعيد كتابة شيء. وفوق ذلك لقطة احتياطية
  تلقائية عند كل تشغيل تغيّرت فيه البيانات (آخر 6 لقطات) وبطاقة تأمين في الإعدادات.
- **مرة واحدة يدوياً**: النسخ حتى 0.1.2 لا تحتوي وحدة التحديث — ثبّت الإصدار الأول من
  [رف الإصدارات](https://github.com/contashepo-create/shopsys-controler-updater/releases/latest) يدوياً، وبعدها كل شيء آلي.

#### كيف تُنشر الإصدارات؟ (آلي بالكامل)
```
أي كود يصل main → سير auto-release: نسخة patch+1 في app/package.json + التزام + وسم vX.Y.Z
                → استدعاء صريح لسير release-windows على الوسم (وسم يدفعه البوت لا يشغّل سيراً
                  تلقائياً بحسب قواعد GitHub) → فحوص → بناء NSIS → نشر إلى الرف العام
```
لا خطوة يدوية. **مسار الإنعاش** لو تعطّل شيء: من تبويب Actions اختر «إصدار ويندوز» ←
Run workflow ← اختر **الوسم** (لا فرعاً) ← Run؛ الفحوص الداخلية ترفض أي مرجع غير وسم `vX.Y.Z`. وقطعة واحدة مطلوبة مرة واحدة: سر `RELEASES_REPO_TOKEN` في هذا المستودع
(Settings ← Secrets and variables ← Actions) بتوكن يملك **Contents: Read and write** على
`shopsys-controler-updater` — بدونه يفشل النشر برسالة واضحة عند خطوة النشر وحدها.

- للتشغيل من المصدر: `cd app && npm install && npm run desktop:dev`
- لبناء المثبّت محلياً على ويندوز: `npm run desktop:dist` (ينتج `app/release/`)
- بوابات التحقق قبل أي دفعة: `npm run verify:all`

### متى تحتاج مساحة الخدمات (SHOPSYS_KV)؟

| الميزة | تحتاج مساحة الخدمات؟ |
|---|---|
| التراخيص · العملاء · رصد الاشتراكات · الإشعارات (٤ أهداف) · «حول» · قائمة الحرق | ❌ لا — تعمل بمساحة التراخيص وحدها |
| قناة الدعم (قراءة ورد) · الإطفاء السريع للميزات · بطاقات الاشتراك · نشر التحديثات | ✅ نعم |

لو كانت غير مضبوطة: تظهر <b>لافتة تنبيه</b> أعلى اللوحة، ومن الإعدادات ← Cloudflare يمكنك
«🔍 اكتشف من الحساب» أو «➕ إنشاء المساحة» والحصول على مقتطف الربط الجاهز فوراً.
